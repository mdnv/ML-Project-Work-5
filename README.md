# Подбор порога классификации игроков

Учебный проект на данных `players.csv`. Логистическая регрессия определяет, относится ли игрок к классу с рейтингом `overall_rating ≥ 80`.

## Что сделано

- Подготовлены числовые признаки; рейтинг, идентификатор и полностью пустые столбцы исключены.
- Данные разделены на train / validation / test в пропорции 60 / 20 / 20.
- Собран пайплайн: заполнение пропусков медианой, масштабирование и логистическая регрессия. Обучение выполнено только на train.
- Получены вероятности через `predict_proba`, построены ROC- и PR-кривые, рассчитаны AUC и AP.
- На validation подобран порог по минимуму стоимости `C_FP × FP + C_FN × FN`.
- На test сравнены accuracy, precision, recall, F1 и матрицы ошибок для стандартного и выбранного порогов.

## Как работает

Модель оценивает вероятность того, что рейтинг игрока не ниже 80. Если вероятность не меньше выбранного порога, игрок получает класс 1, иначе — класс 0.

В учебном примере цена ложной рекомендации FP принята равной 1, а цена пропуска сильного игрока FN — 5. Эти значения являются допущением и задаются в ноутбуке. Снижение порога позволяет находить больше сильных игроков, но увеличивает число ложных рекомендаций.

## Файлы и запуск

- `data/players.csv` — исходные данные.
- `notebooks/classification_threshold.ipynb` — код, графики и выводы.

Открой папку проекта в VS Code, выбери его Python-окружение и установи зависимости:

```bash
python -m pip install pandas numpy matplotlib scikit-learn ipykernel
```

Открой ноутбук, выбери это окружение как ядро и нажми **Run All**. Итоговые метрики и выбранный порог появятся в выводах ячеек.
